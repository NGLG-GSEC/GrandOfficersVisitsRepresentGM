# GrandOfficersVisitsRepresentGM

Φόρμα δήλωσης διάθεσης των Μεγάλων Αξιωματικών για εκπροσώπηση του Μεγάλου
Διδασκάλου σε Εγκαταστάσεις Σεβ. Διδασκάλων, με συγκεντρωτική αναφορά (και
εκτύπωση σε PDF) για τη Μεγάλη Γραμματεία.

- `index.html` — η σελίδα (φόρμα + αναφορά). Φιλοξενείται π.χ. στο GitHub Pages.
- `apps-script/Code.gs` — ο server: αποθηκεύει τις δηλώσεις σε ένα Google Sheet
  και δίνει την αναφορά μόνο με τον σωστό κωδικό.

## Εγκατάσταση (μία φορά, ~10 λεπτά)

1. Ανοίξτε (ή δημιουργήστε) το Google Sheet «Δηλώσεις Εκπροσώπησης Μ.Δ.»
   με τον λογαριασμό Google της Μεγάλης Γραμματείας.
2. Στο Sheet: **Επεκτάσεις → Apps Script**. Σβήστε ό,τι υπάρχει και
   επικολλήστε όλο το περιεχόμενο του `apps-script/Code.gs`. Αποθήκευση.
3. **Ρυθμίσεις έργου (γρανάζι) → Ιδιότητες σεναρίου → Προσθήκη ιδιότητας**:
   - Ιδιότητα: `ADMIN_KEY`
   - Τιμή: ένας νέος, ισχυρός κωδικός (αυτός θα ζητείται για την αναφορά).
4. **Ανάπτυξη → Νέα ανάπτυξη → Τύπος: Εφαρμογή Ιστού**:
   - Εκτέλεση ως: **Εγώ**
   - Ποιος έχει πρόσβαση: **Οποιοσδήποτε**
   - Πατήστε Ανάπτυξη, εγκρίνετε τα δικαιώματα και αντιγράψτε το URL
     (τελειώνει σε `/exec`).
5. Στο `index.html` βάλτε το URL στη γραμμή:
   ```js
   const API_URL = "https://script.google.com/macros/s/.../exec";
   ```
   και ανεβάστε το αρχείο στο repository.

Οι δηλώσεις εμφανίζονται στο πρώτο φύλλο του Sheet (μία γραμμή ανά
αξιωματικό και Εργασία). Για διόρθωση ή ακύρωση μιας δήλωσης, διαγράψτε τη
γραμμή απευθείας στο Sheet.

## Αλλαγή μήνα / Εργασιών

Αρκεί να ενημερώσετε τη λίστα `MEETINGS` στο `index.html`. Κάθε Εργασία
χρειάζεται μοναδικό `id` με λατινικά πεζά, αριθμούς και `_` (π.χ.
`atlas_118`). Το προαιρετικό πεδίο `note` (π.χ. «Εγκαθίδρυση») εμφανίζεται
κάτω από το όνομα της Στοάς. Δεν χρειάζεται αλλαγή στο `Code.gs`.
